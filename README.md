# Glider Wing

A Glider Wing designed to fit on the Eclipson Model B.

This wing was created for fun and I don't recommend using it on an actual Model B unless you are really adventurous. I've only done one flight test and the plane controlled very poorly with a lot of unwanted yaw. Without a gyro I am certain that it would have crashed.

Printed using LW-PLA (Bambu Aero) and fully-assembled with electronics, the wing weighs 361g. For reference, the original Model B wing weighs 235g with the same filament.

# Required Hardware

* 1x 10mm carbon tube, 1m length (optionally 2x500mm, with a short piece of 8mm carbon tube inside to epoxy them together)
* 2x 8mm carbon tube, 450mm length
* 8x flexible hinges, this wing is designed to use TPU hinges by Eclipson
* 2x Eclipson wing servo mounts
* 12x 2mmx8mm M2 screws
* 2x servos
* 2x 300mm servo wire extensions

The STLs for Eclipson wing servo mounts and hinges are available in the free Wolf Go model.

# Printing

I recommend printing cutting each wing in 5 pieces in Bambu Studio. The first 3 pieces should be 250mm each, then the last two at the wing tips should be 125mm each.

Print all pieces in vase mode oriented vertically with the largest end on the build plate. The only exception is the final wing tip piece should be printed with the wing tip on the built plate.

Use 4-7 bottom layers before starting vase mode.

The Aileron should be cut into 3 pieces. One slightly longer piece with 2 hinge holes, then two smaller piece for the remaining length. If they are too long it will wobble on the build plate and produce a bad surface.

The large aileron piece should use about 10 bottom layers before starting vase mode; the control horn should be solid. The other pieces can stick to 4-7 bottom layers.

# Assembly

Should be straight-forward.

* Glue the wing pieces to the carbon tubes and glue the cross-sections of the wing together. Use a liberal amount of CA glue.
* Glue the Aileron pieces together.
* Glue the hinges to the aileron, then glue the aileron to the wing
* Attach servos to servo mounts and screw them to the wing. Use a pushrod to feed the servo wires through the conduit
